## Project Name:
MediQueue
## Features:
- BetterAuth Authentication system(signIn/signUp)
- CRUD operation
- API integration

## 🛠️ Tech Stack

- Frontend: Next.js / React / Tailwind CSS
- Backend: Node.js / Express
- Database: MongoDB 
- Auth: Better Auth / JWT
- Deployment: Vercel
